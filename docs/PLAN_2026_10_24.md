## 3. Sáu workstream

### W1 — Ổn định train (ưu tiên 0)
- Xác định nguyên nhân v25b/B17 ERROR rỗng bằng probe nhỏ: CPU, GPU, competition, dataset.
- Nếu do competition `arc-prize-2026-arc-agi-3`: bỏ source này khỏi kernel metadata (không cần dữ liệu competition).
- Nếu do tổng dataset > giới hạn: giảm source, gộp base shards, hoặc dùng dataset `ornbase-all` 1 nguồn.
- Chỉ push **một kernel GPU tại một thời điểm** cho đến khi ổn định.
- v25b xong → publish adapter → đăng ký fingerprint → chạy 4 gate (B15, B15.5, B16, B17).
- B17 W1 chỉ chạy sau khi v25b có adapter; nếu v22 baseline >20% difficulty thì hạ độ khó.

### W2 — GitHub/HF
- Repo `ornith-lab` (tên chốt với user), nhánh `main` + `ops-state`.
- `.gitignore` chặn secret, log, state, dataset, model, output.
- CI: compile, secret scan, unit test; không cần GPU.
- `ops-heartbeat.yml`: mỗi 10 phút cập nhật issue heartbeat; local tắt vẫn thấy.
- `scripts/github_state.py`: đẩy `state/current.json` lên `ops-state` mỗi 10 phút.
- HF: `ornith-gui-data`, `ornith-gui-adapters`, `ornith-desktop-replay`, `ornith-evals`.
- User cần cung cấp: GitHub key + owner/repo; HF token đã có trong HKCU.

### W3 — OpenChat headless
- `server.py --headless`: không đọc `app.html`, không mở Chrome; API JSON.
- Endpoints: `/api/health`, `/api/ping`, `/api/jobs`, `/api/logs`, `/api/notify`, `/api/events`.
- `client.py`: CLI cho agent, không UI.
- `start.cmd` mặc định headless; `start_ui.cmd` giữ UI legacy.
- `idle_ping.py`: 10 phút/lần khi rảnh, 30 phút/lần khi bận; ghi `scripts/state/heartbeat.json`.
- Không đẩy ping vào session; chỉ event + heartbeat, tránh spam bus.

### W4 — Colab 25h/ngày
- 5 account, mỗi account 1 session; lease để tránh 2 agent dùng chung token.
- Job lifecycle: `pending → starting → running → fetching → done/failed/lost`.
- Keeper poll 60s; ping keepalive 4 phút; TTL; tự reconnect nếu session mất.
- Khi xong: tải `/content/out.log`, artifact zip, upload HF, ghi manifest.
- Scheduler ưu tiên: gate eval > data gen > ablation > desktop test.
- Không chạy 2 job nặng cùng account; token swap phải có lock.

### W5 — Desktop thật (B18)
- X11 thật: Xvfb + openbox + xterm/gedit/thunar/galculator/libreoffice.
- Quan sát = screenshot; hành động = xdotool/wmctrl; checker = file/CLI/OCR.
- 12 task, 9 capability; dummy expert phải pass trước khi đo model.
- Mỗi episode reset app/session; timeout; chống stuck/repetition.
- Chạy trên Colab/Kaggle CPU trước; local Windows dùng WSL2/Docker khi có.
- Đây là benchmark **khó hơn** phase14 (HTML giả lập), không thay thế ngay B15/B16.

### W6 — Vòng lặp tự cải thiện
- Rollout v25b trên B17/B18 → mine failure (stuck, repetition, wrong app, wrong action).
- Sinh task/rollout mới từ failure taxonomy; lọc quality; thêm vào data.
- Train v26 với seed/matrix mới; eval 4-bit; gate; nếu pass → deploy/fingerprint.
- Mỗi ngày benchmark khó hơn: thêm task/capability, không chỉ tăng số episode.
- Lưu mọi run vào `experiments/` (manifest nhỏ) + HF artifact.
