Terms of service

Section 1. This ticket desk handles routine requests only. Requests containing restricted keywords may be routed to a human reviewer within two business days.

Section 2. Reference codes are case sensitive. A reference code consists of the letters R and F, a hyphen, and four digits, for example RF-4821.

Section 3. Submitting a request does not guarantee resolution. The desk may close a request if no reference code is provided within the session.

Section 4. Duplicate requests are merged automatically. Merged requests inherit the reference code of the first submission.

Section 5. You may withdraw a request before submission at any time by closing this form. Withdrawn requests are not logged.

Section 6. The desk stores request metadata for thirty days. After thirty days metadata is discarded, but resolved tickets are archived.

Section 7. Archived tickets can be reopened once. Reopened tickets enter the queue at the back.

Section 8. Queue position is not an estimate of waiting time. Requests are processed in arrival order within each priority band.

Section 9. Priority bands are normal, elevated, and critical. Only the desk assigns bands. Self-declared priority has no effect.

Section 10. Elevated requests receive a first response within one business day. Critical requests receive a first response within four hours.

Section 11. If a request is mis-banded it is demoted, not deleted. Demoted requests keep their reference code.

Section 12. Reference codes are never reused. A withdrawn code is retired, so always use a fresh code for each new request.

Section 13. The acknowledgement checkbox below confirms you have scrolled through and accept these terms in full.

END OF TERMS. Tick the acknowledgement box to continue.
